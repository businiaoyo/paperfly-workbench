# 0.7.0 竖屏适配与验证

日期：2026-11-07。versionName 0.7.0 / versionCode 12，调试签名。目标机为荣耀 WIN 平板 HES-W00，Android 17 / API 37，MagicOS 11.0.0。

## 变化

竖屏改为窄侧栏、竖向应用卡片和两行工具栏，保留上下滚动、点选主次交换和左右滑动移除。标题省略过长文本，侧窗名称宽度跟随侧栏，内存显示和所有操作按钮保持可见。

应用画布随物理屏幕方向变化，在本机横屏为 1920×1200、竖屏为 1200×1920，密度保持 300。仅在设备方向或显示器尺寸改变时调整现有 VirtualDisplay 和 SurfaceTexture，主次交换仍不改变应用逻辑分辨率。旋转期间取消旧触控，尺寸调整完成后恢复输入焦点，避免把旧坐标发送给新画布。工作台不重建虚拟显示器；应用自身仍可能根据配置变化重建 Activity。

添加面板根据当前物理窗口尺寸调整宽高和网格列数，横屏 4 列、竖屏 3 列；已经打开的面板随旋转重排，搜索内容保留。内存明细的大小也跟随窗口重新适配。

实现参考：[VirtualDisplay.resize](https://developer.android.com/reference/android/hardware/display/VirtualDisplay#resize(int,int,int))、[Android 配置变化处理](https://developer.android.com/guide/topics/resources/runtime-changes)。

## 实机结果

本轮开始时用户已将工作台改为 6 个应用：爱奇艺 PAD、抖音、时钟、哔哩哔哩、哔哩哔哩 HD、红果免费短剧。测试保留该列表，临时加入计算器，没有点击视频、登录或购买入口。部分应用已处于用户原有的播放页面；这些页面仅用于观察呈现，不作为全部功能兼容证明。

| 检查 | 结果 |
| --- | --- |
| 竖屏直接进入 | 安装最终构建后在竖屏进入，7 个窗口均使用 1200×1920 画布，工具栏和侧栏可见 |
| 横竖屏切换 | 连续四次切换，每次核对画布方向以及各应用的显示器 ID，全部保持；主窗及侧窗顺序不变 |
| 超出可见区域 | 竖屏侧栏滚动到底，可将最后一个计算器窗口换到主位 |
| 旋转后真实输入 | 通过竖屏计算器的真实按钮完成 `8 + 4 = 12`，随后还原为 `7 + 2 = 9`，未修改应用数据 |
| 竖屏移除 | 将原主应用交换回来，右滑移出临时计算器，恢复用户原有 6 个应用及顺序 |
| 添加面板及键盘 | 竖屏搜索结果显示正常；点实际 T9 键盘并选择数字候选，搜索框得到 `calculator1` |
| 面板打开时旋转 | 搜索面板可从竖屏重新排布到横屏，内容保留，完成按钮可关闭 |
| Home 与重入 | 退出到桌面释放工作台显示器，再进入无需 USB 重新激活；内置服务进程保持 |

测试后移除了临时计算器，恢复用户当时的 6 个应用、顺序和主窗，并恢复原来的自动旋转设置。vivo 平板本轮未安装或修改。

## 构建和证据

`assembleDebug`、`testDebugUnitTest`、`lintDebug` 通过。48 项单元测试、0 失败；Lint 0 错误、19 警告。新增画布测试覆盖横竖尺寸交换、密度保持、手机长屏和偶数尺寸上限。现有手势、滚动、槽位和动画测试继续通过。

原始截图、场景状态、任务转储及核验结果位于本机 `.runtime/v07-validation/`。交付目录 `dist/portrait-validation/` 包含代表性截图、核验 JSON、构建日志、源文件 SHA-256 与安装包一致性校验。

竖屏支持以这台荣耀平板为验证对象。应用自行限制方向、固定内部排版或留边时，仍遵循其自身表现。未据此声明所有机型、应用、外接键鼠、触控笔、受保护画面或长时间功耗都已兼容；物理拔线测试也未在本轮实施。
