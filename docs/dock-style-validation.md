# Dock 样式与总览移除：0.17.0-test.5

2026-11-13，versionCode **43**，schema **8** 不变。本轮目标为联想 Y700 TB323FU（`HA2HEFTM`，Android 16）。没有发布 NAS，未操作荣耀或 vivo。

## 用户要求与改动

用户要求修正 Dock 的样式，并确认“不需要总览”。本轮因此移除整个窗口总览，不只是隐藏田字格按钮。

- Dock 改为按真实内容测量宽度，修正旧 `items × 48 + 132` 估算造成的右侧空白和分区宽度偏差。空、单个、多个应用均按内容收紧，最大宽度由屏幕安全边距限制。
- 内部分为可横向滚动的应用条和固定的添加按钮，应用较多时加号仍在右侧可点。固定/运行/最近应用继续使用既有分区与去重模型。
- 统一 48 dp 点击区、34 dp 应用图标、矢量加号、低对比半透明背景和细边框。运行点、最小化短线、选中短条直接绘制，避免字体基线带来的错位。选中应用使用轻底色和细轮廓。
- 以窗口 ID / 启动组件复用 Tile；焦点、图标等刷新不重建整排，保留滚动位置，选中的屏外应用自动滚入可见区。图标 Drawable 尽可能复制 ConstantState，避免不同 View 争用同一个 Drawable 回调。
- 删除 `OverviewPages`、`OverviewControls`、`WindowOverview`；同时清理总览几何、展示状态、分页/过滤、标题及命中分支。移除 Dock、主菜单、同应用窗口菜单、四/五指上滑和 Ctrl+Alt+O 的总览行为与说明。
- 保留应用切换、添加、最小化恢复、分屏、自由布局、多实例、两种全屏、左右多指切换及其他快捷键。Dock 高度和普通画布占位不变，不因外观改动 resize 应用。

数据没有新增或删减字段，schema 8 不变。配置、目录读取、几何、UI 和 shell 服务边界保持；没有增加服务权限。旧验证文档中关于总览的内容是历史能力，不能再当当前产品入口。
