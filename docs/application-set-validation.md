# 0.11.0 应用组合启动验证

2026-11-08。versionName 0.11.0 / versionCode 19，调试签名。在荣耀 WIN 平板 HES-W00、Android 17 / MagicOS 11 上安装、激活和实测；vivo 参考机未修改。

应用组合保存一次工作台使用的应用列表，选中后一起进入主窗和侧栏；分屏卡片保持为单独功能。启动页增加已保存组合的一键打开卡片、应用摘要和新建入口。当前已加入的应用也可从工作台菜单保存为组合。存储格式不变，既有保存组合和分屏布局继续按原定义打开。

实测流程：

1. 重新快照用户当前配置。此次已是 6 个应用，含计算器/时钟的原有分屏和用户后来加入的应用，未用历史 9 应用快照恢复。
2. 在启动页新建 `ThreeApps`，选择计算器、时钟、设置。空选择不能保存；选择期间旋转为竖屏，已有选择保持。
3. 保存后当前工作台定义完全不变，设备没有创建工作台显示器。新组合包含三个独立单应用卡片。
4. 启动页点一次 `ThreeApps`：三个真实应用一起载入，主位一个，侧栏两个，无逐个加入步骤。
5. Home、强停 App、重新打开后，再点一次仍能载入全部三个应用。横竖屏选择、普通/全屏和“分屏卡片”入口已检查。
6. 通过临时保存快照恢复用户原来的 6 应用配置，核对完整定义与操作前一致，包括成员、顺序、焦点、卡片 ID、样式和原有分屏参数；随后删除临时快照。已有两个保存组合与操作前一致，额外保留 `ThreeApps` 示例。

构建、架构检查、79 项单元测试均通过；Lint 0 错误、26 警告。新增回归测试验证保存三个独立应用后可反复激活，期间修改当前工作台不会改变已保存组合；既有分屏、迁移、失败保护、输入/动画测试继续通过。

原始快照、截图与日志位于 `.runtime/v011-validation/`。最终 APK、SHA256 与证据位于 `dist/application-set-validation/`。测试限于当前荣耀设备；0.10 中已记录的应用兼容性限制继续适用。

最终停留在新的应用组合启动页；“继续上次工作台”也已通过强停重开验证，保留用户当前 6 应用及原分屏配置。
