2026-11-07，versionName 0.10.0 / versionCode 18，调试签名。单 APK，无新增运行时库或危险权限。在荣耀 WIN 平板 HES-W00、Android 17 / API 37、MagicOS 11.0.0 上安装、USB 激活并实测。vivo 参考机未安装或修改。

## 返回问题

实机抓到“Application does not have a focused window”的输入 ANR：承载窗口原先不可获取焦点，关闭面板后物理显示器的返回输入可能没有接收者。承载窗口改为可聚焦并使用 `FLAG_ALT_FOCUSABLE_IM`，系统返回与“返回应用”走同一条返回接口。

服务在拥有的显示器内发送带系统标记的完整按键，并等待分发完成；界面收到结果后根据当前弹窗/成员重新确认焦点，避免异步恢复抢走新弹窗的输入。WLAN 独立页面返回设置主界面的真实画面已核对。

另复现时钟首页按返回后任务结束、虚拟显示器为空而黑屏。服务仅在对应的自有显示器没有可见任务时恢复该应用入口。时钟组内首页返回和物理显示器系统返回后恢复画面已检查，不关闭组内计算器。根页恢复可能重新打开该应用入口，不能等同于恢复其任意页面。

## 画布和渲染修正

保留有效 TextureView/Surface，不在每次关闭弹窗时替换所有消费端。为每个成员选择独立画布与适当密度，避免小窗口沿用大窗口密度导致控件拥挤。

捕获到旋转通知早于场景实际尺寸改变的时序：先用旧场景计算成员画布、后续因全局画布尺寸相同而漏更。现在实际场景尺寸改变会重新计算成员画布，配置通知不提前按旧场景提交最终布局。对有自定义比例的双应用组合复测横竖屏，最终成员画布比例正确，强停重开保持相同结果。

厂商应用不保证支持任意极短、极窄比例；本轮实测以两个成员为主，三成员的比例分配由单元测试验证。荣耀电子邮件首次使用页仍有既有等待画面问题，不计入兼容性通过，未操作其账户或授权。长期功耗、更多应用/输入法、键鼠和其他设备尚需进一步实测。
