# 0.14.1 窗口利用率、侧栏与选择页

2026-11-11，联想 TB323FU / Android 16。iQOO 仅以本日原生工作台截图对照，本轮没有在 iQOO 安装或改变设置。实机操作前重新快照：哔哩哔哩主窗、爱奇艺与超级文件两张侧卡片，普通模式，自动旋转 1、user_rotation 1。超级文件是用户本轮已加入的应用，不能用上一轮的两应用快照覆盖。

## 实现

- 去掉横向深色工具栏、常驻主应用名称和内存文字。正常模式只在侧栏上方保留返回与菜单两个 44 dp 触控入口；窄侧栏收为菜单。应用名称、全屏、添加管理、组合、外观、分屏、内存和退出留在菜单。系统栏透明；主窗上方没有透明但仍拦截触摸的整行 View。
- `StageLayout` 直接分配侧栏以外的主区域，普通模式上下各 8 dp，不再按整屏比例缩放后居中。实际应用画布仍由同一主区域经 `PaneLayout` / `CanvasSize` 推导。自定义比例和缩放仍按用户配置留白。
- 侧栏取消名称行，换为左下角 30 dp 应用图标；无障碍名称和长按提示保留，分屏卡片带成员数。四张侧预览可同时呈现，第五项加号继续向下滚动可达，更多应用不无限缩小。
- 单应用侧卡片使用轻微 Y 轴透视和转角，交换时由原 `StageMotion` 连续回正/倾斜，不主动分配额外截图或硬件层，不重建任务、显示器或 Surface。平台仍可能为合成分配内部资源。静止时无额外循环；相机距离和轴心只在画布尺寸改变时更新。多应用卡片暂时保持平面，避免成员接缝。
- 初版透视与系统立体阴影组合产生了偏移的灰色块，已关闭卡片轮廓投影，继续保留裁剪圆角与 Z 排序。
- 选择页采用独立、更深的灰蓝遮罩，正文与辅助文字提高对比度。模糊半径仍不超过 150 px；视觉增强主要来自遮罩，系统禁用模糊时使用更不透明的回退背景。未新增读壁纸权限或图片复制。[Android 模糊性能建议](https://source.android.com/docs/core/display/window-blurs)

`StageControls`、`RailAppBadge`、`StageCardPose` 分别负责控件、图标与变换；布局继续集中在 `StageLayout`，未修改配置字段/schema，也未改变服务权限和应用接续。透视使用 Android View 合成变换；实际成本需以设备采样为准，不能称为零开销。[Android 硬件加速说明](https://developer.android.com/topic/performance/views/hardware-accel-views)

## 短时帧采样

均为本机横屏、普通模式、原三应用，按相同侧卡片位置进行八次主次交换，间隔约 650 ms，使用 `dumpsys gfxinfo ... framestats`。每次先清空统计；应用内容和系统负载未固定，不是受控跑分，也不能替代长期功耗测试。

| 版本 | 统计帧数 | Janky frames | 帧耗时 P50 / P95 / P99 | GPU P50 / P95 / P99 |
| --- | ---: | ---: | --- | --- |
| 0.14.0 原布局 | 944 | 0（0%） | 5 / 5 / 6 ms | 4 / 4 / 5 ms |
| 0.14.1 新布局，临时关闭倾斜 | 924 | 2（0.22%） | 5 / 8 / 16 ms | 4 / 7 / 11 ms |
| 0.14.1 新布局，最终倾斜 | 922 | 3（0.33%） | 7 / 13 / 13 ms | 4 / 10 / 10 ms |

对应 `baseline-gfx.txt`、`flat-gfx.txt`、`final-gfx.txt`。新布局自身也扩大了实时应用面积；倾斜对照的 P50 增加约 2 ms、P95 增加约 5 ms。本次掉帧比例较低，因此保留轻微倾斜，但不宣称零开销或所有设备流畅。临时平面构建仅用于比较，交付构建已恢复倾斜。初版透视阴影问题及其采样保留在 `first-landscape.png` / `new-gfx.txt`，不作为最终结果。

右侧栏镜像有布局单测，本轮未在联想切换右侧栏实测。多应用分屏卡片的平面分支、关闭系统模糊后的回退、其他机型与长时间功耗仍待专项实测；本轮未修改持久化 schema 和服务权限。
