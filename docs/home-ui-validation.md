# 0.14.8 首页改版

2026-11-11。在联想 TB323FU（`HA2HEFTM`，Android 16）安装并验证。没有操作 iQOO 参考设备。原始证据在 `.runtime/home-ui-20261111/`，首页截图副本在 `dist/home-ui-validation/`。

## 改版与模块边界

原首页以连续长按钮和说明文字排列，激活入口长期占据主要位置，继续工作台需要向下寻找。新版首页以浅色背景和深绿主卡片建立层级：

- 顶部仅显示名称、简短介绍、状态和帮助入口；激活后收起引导。未激活时保留明确的激活按钮，组合仍可先创建。
- 主卡片展示上次应用名单、数量及图标组成的布局示意，突出“继续工作台”；最近应用是独立次级卡片，竖屏改为横向列表。
- 保存组合显示应用图标、名称、应用摘要和数量；按可用宽度排为一至三列，空态提供新建入口，管理入口保留。
- 版本、USB 激活说明和诊断收进“帮助与设置”；无线激活流程及原有诊断页面继续复用。

`HomeScreen` 只负责 View 和响应式布局，`MainActivity` 保留状态、生命周期与业务回调。图标和名称由 `HomeAppAssets` 在独立线程读取，加载代次及关闭检查阻止旧结果覆盖新页面。`HomeWorkspacePreview` 是静态示意，使用真实应用图标，保留多应用卡片的组边界；它不启动应用、不截图或创建 Surface，也不是工作台的实时缩略图。

横屏入口行使用明确的共享高度并考虑字体比例，避免激活引导隐藏后被 ScrollView 的测量过程拉高；窄屏改为自然高度。按钮保留触控面积、点击反馈和无障碍名称。配置 schema、组合 ID、最近应用接续、服务权限、工作台几何和显示器处理均未修改。
