## 安装与激活

当前测试包为 `dist/OpenWorkbench-0.17.0-test.7-standalone-debug.apk`。安装后打开首页“开始激活”，也可从右上角“帮助与设置 → 无线激活”进入。`dist/` 为本机交付目录，未包含在源码版本控制中；缺少安装包时按下方构建步骤生成。

1. 点“开始配对并打开系统设置”，允许配对通知。
2. 在开发者选项中开启无线调试，点“使用配对码配对设备”。荣耀/华为先开启“仅充电模式下允许 ADB 调试”并保持“USB 调试”开启；无需插着 USB。
3. 保持系统配对弹窗打开，下拉通知，在“开放工作台 · 无线激活”中输入 6 位配对码。
4. 激活成功后自动进入工作台，左上角可返回管理首页。已配对设备以后可直接点“已配对，直接激活”。

通知不可用时可将本页与系统设置分屏，手动填写配对端口和配对码；端口发现失败也可手动填写连接端口。App 只连接本机回环地址，密钥保存在不备份的私有目录，配对码不保存。完成激活后，App 会主动关闭 ADB 连接，窗口和输入通过本机服务继续处理。

USB 备用方式：连接电脑、允许调试，运行 `dist/重新激活工作台.command`。多台设备均装有 App 时指定目标：

```sh
bash scripts/activate-usb.command 目标设备序列号
```

设备重启、APK 更新或辅助服务被系统终止后需要重新激活（可在 App 内完成）；普通退出和重新进入无需再激活。已验证荣耀 WIN 平板 HES-W00、Android 17 / MagicOS 11；vivo 为原生模式研究参考，未安装本 App。无线调试关闭后的验证边界见本版记录；长期功耗、重启后的自动恢复及更多厂商仍需独立验证。

## 使用

**应用组合**保存“工作台要使用哪几个应用”；**分屏卡片**控制“同一张卡片里怎么显示多个应用”。

1. 启动页点“＋ 新建应用组合”，选好应用后点“选好了”，命名保存。
2. 已激活时启动 App 直接恢复当前工作台。左上角返回管理首页，点组合卡片即可一次打开所有成员，分别加入主窗和侧栏。
3. 已在工作台添加好应用时，用“••• → 应用组合 → 保存当前应用列表为组合”。


- 点侧栏末尾“＋ 添加应用”或“••• → 添加与管理应用”搜索，点选一个后立即关闭并加入应用。“已加入”列表可移除、调整侧卡片顺序和选择应用；组合编辑继续支持多选。
- 首页“从最近应用进入工作台”接续最近五个可启动的后台应用，最近一个作为主窗，原有卡片继续保留。继续上次及打开保存组合按各自的原列表进入。
- 点侧卡片与主卡片交换；上下滑动浏览，左右滑动移除整张侧卡片。组内移除单个应用通过“已加入”或“移出当前应用”。
- “••• → 应用组合”：保存当前配置为新组合、创建空白工作台。点已保存组合可打开、重命名、明确覆盖、删除或添加桌面快捷方式。当前状态自动保存，已保存组合只在显式覆盖时更新。
- “••• → 外观与比例”：侧栏左右位置、宽度、紧凑卡片、主窗缩放、自动/16:10/16:9/4:3/1:1 宽高比，以及桌面壁纸虚化、颜色/渐变和自选图片背景。旧配置保留原背景，可手动切换为桌面壁纸；自选图片通过系统文件选择器授权读取。
- “窗口布局 → 分屏比例与方向”：将其他卡片合并到主卡片，或拆分为独立应用；可选自动、左右或上下排列，以及均分所有应用。每对相邻应用都有分隔条，拖动实时调整两侧窗口，点按打开设置。点主卡片内的应用改变输入焦点，菜单标题显示当前成员。
- 保存组合中的“添加桌面快捷方式”打开系统确认。快捷方式按组合 ID 启动；未激活时先显示激活入口，组合删除后相应快捷方式停用。
- 从屏幕右边缘向内滑动返回当前成员，滑回边缘可取消；工作台弹窗内先关闭弹窗。“返回应用”和物理显示器上的系统返回转发给当前成员，按应用自身规则收起输入法或返回上页；若根页面关闭任务导致该显示器为空，在原显示器恢复对应应用入口。
- “••• → 工作台全屏”收起侧栏顶部入口和系统栏，保留侧卡片；左下角“菜单”打开菜单，可选“退出全屏”或“当前应用全屏”。
- “••• → 当前应用全屏”隐藏侧栏，只放大当前焦点应用；分屏卡片先点想放大的成员。左下角“返回工作台”恢复原卡片、顺序和普通/工作台全屏模式。系统返回手势仍返回应用内上一页。
- 两种全屏的进入/退出均保留应用逻辑画布、显示器及有效 Surface，不为全屏发起 resize；保持原比例，区域比例不同时留边。旋转或主动修改布局仍可能触发应用自己的配置变化处理。
- “••• → 内存占用”可查看分项，约每 15 秒后台采样 PSS；包含应用本身内存，不等于工作台的新增开销，部分图形和系统开销不在其中。
- “••• → 退出工作台”或 Home 结束当前会话并释放显示器。横竖屏和配置变更调整原显示器尺寸；主次交换复用显示器和画面。

实际承载数量取决于内存、图形资源及系统策略。应用需支持所选的副屏/窗口比例；特别窄小的组合、受保护画面、厂商首次使用页面、第三方输入法、键鼠与触控笔需进一步适配。荣耀电子邮件首次使用页面仍有等待画面的既有兼容问题，未操作其账户或授权。
